Instant wake for Astra

Astra’s ChatGPT chat rests between turns, like Claude’s. Semaphore wakes it when it’s Astra’s turn.

How it works

ChatGPT runs Codex through a shared engine on this Mac that Semaphore can also reach. Turning this on adds a login item and a setting that points ChatGPT at that engine, so every Codex chat in ChatGPT uses it after one restart. The engine is an experimental Codex feature. Turn this off anytime, and ChatGPT goes back to its own engine after its next restart.

Conversations are saved on this computer. Semaphore has no hosted account, analytics, or API key to configure.
