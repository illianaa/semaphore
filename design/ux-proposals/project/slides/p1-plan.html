Semaphore · three ways forward

Proposed send-anytime contract: append each human message to the room journal immediately with a unique request ID, without moving ownership or changing the active turn's context snapshot. Before a reply commits, check for newer human messages. If any exist, return them for explicit acknowledgment and review under the same turn, then accept the revised reply. This check and commit share the room lock. The latest explicit human Reply next choice overrides the AI's nomination at the next handoff, subject to pause, required human input, the four-turn cap and recipient availability. Mid-turn messages do not reset the cap. At the cap, the choice waits for an explicit continuation. Sending does not interrupt a tool call or undo edits already made. The UI says when input is saved and when the current AI has read it. Prompt counts describe intended build rounds, not a completion guarantee. The extra scheduling logic makes P1 low to medium risk.
